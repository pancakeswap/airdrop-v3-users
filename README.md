# Airdrop V3 Users

This repository provides tools, data, and scripts related to **PancakeSwap Airdrop V3 users**.  
It is designed to help developers and contributors easily work with airdrop eligibility data, Merkle proofs, and related resources.

---

## 🚀 Features

- 📄 CSV files containing airdrop user data
- 🌳 Merkle proof data for Airdrop V3
- ⚙️ Scripts for frontend and smart contract usage
- 🧩 Clean and simple project structure

---

## 🛠 Requirements

Make sure you have **Bun** installed.

Check:

```bash
bun --version


To install dependencies:

```bash
bun install
```

To run:

```bash
bun run index.ts
```

This project was created using `bun init` in bun v0.5.9. [Bun](https://bun.sh) is a fast all-in-one JavaScript runtime.
